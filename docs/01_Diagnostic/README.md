# 01 – Objectifs et ressources

Cette séance lance le module **Cosmétologie** par une question simple mais fondamentale : **qu’est-ce qu’un produit cosmétique ?**  
L’objectif est de savoir **mobiliser la définition réglementaire**, distinguer les **grandes catégories** de produits, et surtout traiter les **produits frontières** (cosmétique vs médicament vs biocide vs dispositif médical).  
👉 Compétences ciblées : **mobiliser** une définition officielle et **argumenter** un statut produit (réflexe “épreuve E2”).

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Définition réglementaire** | Définition officielle d’un produit cosmétique + notion d’usage “externe” |
| **Catégories de produits cosmétiques** | Nettoyant, hydratant, maquillage, capillaire, parfum, hygiène, etc. |
| **Produit frontière** | Cas ambigu : quand ce n’est **pas clairement** un cosmétique (revendication, usage, zone, action) |
| **Allégation / revendication** | “Ce que le produit promet” : c’est souvent **elle** qui fait basculer le statut |
| **Critères d’analyse rapide** | Zone d’application, finalité, mode d’action, public, mention “thérapeutique”, etc. |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Citer la définition réglementaire et l’utiliser correctement dans une justification |
| **Argumenter** | Conclure “cosmétique / pas cosmétique” avec une justification structurée (preuve → conclusion) |

## 🔬 “Test rapide” : Est-ce un cosmétique ?

```

1. Où s’applique le produit ?

   * Parties superficielles du corps (peau, cheveux, ongles, lèvres…)
   * Dents / muqueuse buccale

2. À quoi sert-il (finalité) ?

   * nettoyer / parfumer / protéger / maintenir en bon état / modifier l’aspect
   * corriger les odeurs corporelles

3. Que promet-il (allégation) ?

   * Si le produit prétend “soigner”, “guérir”, “traiter une maladie”
     → alerte : ce n’est peut-être plus un cosmétique.

Conclusion :

* Si (zone + finalité + allégation) sont cohérentes → COSMÉTIQUE
* Sinon → PRODUIT FRONTIÈRE (à analyser finement)

```

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| La **définition** est une preuve | On ne “devine” pas : on **justifie** avec la règle |
| Les **allégations** orientent le statut | “Anti-acné curatif”, “antifongique”, “désinfecte” = vigilance |
| Un produit frontière se traite avec méthode | Zone + finalité + action + revendication |
| À l’E2, on attend une **argumentation structurée** | Constat → règle → conclusion (sans blabla) |

## ⚠️ Lien explicite avec l’épreuve E2

> Objectif : **Mobiliser une définition réglementaire pour justifier le statut d’un produit**  
> (réflexe attendu dans des questions type **E2 2025 – Q12** : “produits frontières”).

Mini-attendu typique :
- **Je cite la règle** (définition cosmétique + finalités autorisées),
- **Je repère l’élément qui fait basculer** (souvent l’allégation),
- **Je conclus** clairement : “cosmétique / non cosmétique / produit frontière”.
