# 03 – Objectifs et ressources

Cette séance te rend autonome sur une compétence **très attendue en E2** : lire une **étiquette cosmétique** et comprendre ce que révèle la **liste INCI** sur la formule.  
On apprend à repérer les **mentions obligatoires**, à comprendre les **règles d’écriture INCI** (latin/anglais), l’**ordre décroissant**, et la règle du **seuil 1 %**.  
👉 Compétences ciblées : **analyser** un étiquetage et **communiquer** une conclusion claire et justifiée (type E2 2025, Q12–13).

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **INCI** | Noms normalisés des ingrédients (langue, conventions) |
| **Mentions obligatoires** | Informations réglementaires attendues sur le packaging |
| **Latin / anglais** | Botanique souvent en latin ; ingrédients “classiques” souvent en anglais |
| **Ordre décroissant** | Jusqu’à 1 %, les ingrédients sont listés du plus au moins concentré |
| **Seuil 1 %** | En dessous de 1 %, l’ordre devient libre (zone “fin de liste”) |
| **Lecture “formule”** | Déduire : base, type de galénique, présence d’actifs, parfum, conservateurs |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Analyser** | Lire une liste INCI et en déduire des informations sur la formule |
| **Communiquer** | Rédiger une réponse claire : constats INCI → interprétation → conclusion |

## 🔍 Méthode express : lire une liste INCI comme un(e) pro

```

ÉTAPE 1 — Repérer la BASE

* Début de liste = ingrédients majoritaires (souvent eau, huiles/esters, tensioactifs…)
* Si "Aqua" est premier → base aqueuse (souvent)

ÉTAPE 2 — Identifier la FAMILLE du produit

* Tensioactifs tôt dans la liste → produit lavant (gel douche, shampoing)
* Huiles/esters + émulsifiants → crème/lait/émulsion
* Polymères/gélifiants → gel

ÉTAPE 3 — Chercher les “indices” (fin de liste)

* Parfum / allergènes parfumants
* Conservateurs (souvent vers la fin)
* Colorants (CI …)
* Actifs souvent proches/au-delà du seuil 1 % → effet parfois limité mais pas toujours

ÉTAPE 4 — Conclure en 3 lignes
Constats (INCI) → Interprétation → Conclusion (type produit + points forts/vigilance)

```

---

## 🧾 Rappel : règles INCI à connaître

```

✅ Ordre décroissant de concentration (jusqu’à 1 %)
✅ Sous 1 % : ordre libre (fin de liste)
✅ Botanique : souvent en latin (Nomus botanique + partie + extract…)
✅ Parfum : "Parfum" + parfois allergènes listés
✅ Colorants : "CI" + numéro

```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Le début de liste = la base | C’est ce qui “fait” le produit au quotidien |
| Le seuil 1 % change l’interprétation | Fin de liste ≠ “quantité zéro” mais souvent faible |
| Latin/anglais = convention INCI | Ne pas confondre avec “ingrédient exotique” |
| INCI permet d’inférer la galénique | Lavant / émulsion / gel… grâce aux familles repérées |
| À l’E2 on attend une réponse structurée | Observation → déduction → conclusion claire |

## ⚠️ Lien explicite avec l’épreuve E2 (Q12–13)

> Objectif : **Analyser un étiquetage INCI et en déduire des informations sur la formule.**

Attendu typique :
- Tu cites **2–4 éléments INCI** (début + indices fin),
- Tu déduis **le type de produit / la base / points de vigilance**,
- Tu communiques une conclusion **courte, claire, argumentée**.

Exemple de structure de réponse (format E2) :
- **Constats :** “Aqua en 1er, puis … ; présence de … ; parfum + conservateurs en fin de liste.”
- **Interprétation :** “Produit majoritairement aqueux, formule de type …, parfumée, conservée…”
- **Conclusion :** “Probablement un … ; points forts … ; vigilance …”
