# 14 – Objectifs et ressources

Cette séance introduit les formes galéniques cosmétiques : solutions, gels, émulsions et autres dispersions. Les étudiants apprennent à identifier, nommer et relier chaque forme à son usage professionnel. C'est une séance fondatrice pour tout le bloc 2.

---

## 🎯 Objectifs

### Objectifs scientifiques

- Distinguer les **formes homogènes** (solutions, gels) et les **formes hétérogènes** (dispersions)
- Identifier les **4 grandes familles** : solution, gel, émulsion, solide/poudre
- Connaître la **composition type** et le **stabilisant** de chaque forme
- Distinguer les émulsions **H/E**, **E/H**, **multiples** et **microémulsions**
- Relier la **forme galénique** à l'**usage** et à la **cible**
- Reconnaître la forme à partir d'une **description** ou d'une **liste INCI**

### Objectifs méthodologiques (E2)

- Identifier une forme galénique avec des **preuves** issues du dossier
- Argumenter le lien **forme ↔ usage ↔ cible**
- Utiliser la **méthode G.A.L.E.N.I.Q.U.E.** (FM07)

## 🔬 "Test rapide" : Les formes cosmétiques

```
1. Quelle est la différence entre une forme homogène et une dispersion ?
   → Forme homogène = 1 phase (substances miscibles). Dispersion = 2+ phases NON miscibles + stabilisant.

2. Quelles sont les 3 composantes obligatoires d'une émulsion ?
   → Phase AQUEUSE + phase HUILEUSE + ÉMULSIONNANT (tensioactif)

3. Émulsion H/E : quelle est la phase continue ?
   → L'EAU (l'huile est dispersée en gouttelettes dans l'eau)

4. Quel stabilisant est spécifique des gels ?
   → Le GÉLIFIANT (carbomer, xanthane, HEC…)

5. Comment s'appelle le phénomène de rupture d'une émulsion ?
   → La COALESCENCE (les gouttelettes grossissent et les phases se séparent)

6. Citez 3 formes hétérogènes (dispersions) autres que l'émulsion.
   → SUSPENSION, MOUSSE, AÉROSOL (+ poudre)
```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Homogène = 1 phase | Solutions (vraies, ioniques), gels (hydrophiles, oléogels) |
| Hétérogène = 2+ phases non miscibles | Émulsions, suspensions, mousses, aérosols, poudres |
| Chaque forme a son stabilisant | Émulsionnant (émulsion), gélifiant (gel/suspension), raidisseur (poudre) |
| H/E = eau continue, huile dispersée | Fluide, léger, se rince → lait, crème de jour |
| E/H = huile continue, eau dispersée | Onctueux, riche, ne se rince pas → cold cream, crème modelage |
| Microémulsion = TA × 4-5 | Aspect transparent ; pénétration des actifs **potentiellement favorisée** (selon formulation) |
| Coalescence = rupture émulsion | Les gouttelettes grossissent → séparation des phases |
| FM07 = méthode G.A.L.E.N.I.Q.U.E. | Identifier + preuves + relier usage/cible |
