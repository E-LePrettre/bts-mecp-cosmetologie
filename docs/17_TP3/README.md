# 17 – Objectifs et ressources

Troisième TP de cosmétologie. Les étudiants formulent une crème douche au beurre de karité (émulsion lavante H/E, **252 g ≈ 250 mL**) en suivant un protocole de fabrication, puis réalisent des contrôles qualité (organoleptique, pH, stabilité, pouvoir moussant).

---

## 🎯 Objectifs

### Objectifs scientifiques

- Formuler un produit cosmétique lavant en respectant un **protocole**
- Identifier les **phases** (A = chauffée, B = ajouts à froid) et comprendre l'**ordre d'incorporation**
- Identifier les **familles de tensioactifs** présents (amphotère, non ionique, anionique doux)
- Comprendre la différence **crème douche** (émulsion lavante) vs **gel douche** (gel monophasique)
- Mesurer et ajuster le **pH** (spécification 5,5–6,5 ; **cible 5,5**)
- Réaliser des **contrôles qualité** (organoleptique, stabilité, mousse)

### Compétences E2

- Mettre en œuvre un protocole
- Observer et mesurer
- Analyser une formule (INCI, familles TA, forme galénique)
- Argumenter (lien formulation ↔ usage ↔ cible)

## 🔑 Points clés

| Notion | Ce TP illustre... |
|--------|-------------------|
| Émulsion H/E lavante | Crème douche ≠ gel douche (2 phases, aspect blanc laiteux) |
| Association de TA | Amphotère + NI + anionique doux → lavant + doux + moussant |
| **Olivem 1000 (NI)** | Stabilise la phase huileuse (karité) dans la phase aqueuse → émulsion H/E |
| Phases A/B | **A chauffée (75–80 °C)** → émulsification → **B à froid** (fragrance + Cosgard) |
| pH 5,5-6,5 | Compatible pH cutané, respecte le film hydrolipidique |
| Stabilité | Centrifugation → déphasage = coalescence |
| Pouvoir moussant | Test de Ross-Miles → hauteur de mousse + stabilité |
