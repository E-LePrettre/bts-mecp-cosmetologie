## 🔬 "Test rapide" : Parfumerie (2/2)

```
1. Quelles sont les 3 notes de la pyramide olfactive ?
   → Tête (15-30 min), coeur (2-4h), fond (6-24h+)

2. Citez 4 familles olfactives.
   → Hespéridée, florale, orientale, boisée (+ fougère, chypre, cuir)

3. Quelle est la concentration d'une EDP ?
   → 15-20 % de concentré parfumant

4. Quels sont les 3 rôles du parfum dans un cosmétique ?
   → Masquer, caractériser, plaire

5. Citez 2 contraintes du parfumage en cosmétique bio.
   → HE uniquement (COSMOS), allergènes à déclarer (CE 1223/2009)

6. Citez les 4 facteurs de dégradation d'un parfum.
   → Lumière (UV), oxygène, température, temps
```

| Idée clé | À retenir |
