# 21 – Objectifs et ressources

Séance en classe inversée (CI) sur les cosmétiques biologiques et naturels. Les étudiants lisent une capsule préparatoire à la maison (labels, référentiels, définitions) puis exploitent en classe : comparaison d'INCI bio/conventionnel, distinction label/allégation, contraintes de formulation bio.

---

## 🎯 Objectifs

### Objectifs scientifiques

- Distinguer **naturel**, **d'origine naturelle** et **biologique**
- Connaître les **3 référentiels** : COSMOS (Organic/Natural), NaTrue, Nature et Progrès
- Distinguer **label certifié** et **allégation** autoproclamée
- Analyser un **INCI bio** (astérisques, ingrédients interdits/autorisés)
- Comprendre les **contraintes de formulation** bio (TA, conservateurs, émulsifiants)
- Argumenter sur le positionnement bio/naturel d'un produit

## 🔬 "Test rapide" : Labels bio

```
1. Quelle est la différence entre « naturel » et « bio » ?
   → « Naturel » = autoproclamé. « Bio » = certification indépendante selon un cahier des charges.

2. Citez 3 familles d'ingrédients INTERDITS en cosmétique bio.
   → Silicones, PEG, parabènes (+ phénoxyéthanol, pétrochimie, colorants de synthèse)

3. Que signifie l'astérisque (*) dans une liste INCI bio ?
   → Ingrédient issu de l'agriculture biologique

4. Quel est le référentiel bio le plus exigeant ?
   → Nature et Progrès (100 % naturel, 100 % végétaux bio)

5. COSMOS Organic vs COSMOS Natural : quelle différence principale ?
   → Organic exige ≥ 95 % des végétaux bio + 20 % bio total. Natural n'a pas d'obligation bio.

6. Comment distinguer un label d'une allégation sur l'emballage ?
   → Label = logo + nom du certificateur. Allégation = mention sans logo ni certification.
```

---

## 🔑 Points clés

| Notion | Ce qu'il faut retenir |
|--------|----------------------|
| Naturel ≠ bio | « Naturel » = pas de garantie ; « bio » = certifié |
| COSMOS Organic | ≥ 95 % végétaux bio, ≥ 20 % bio total, interdits : silicones/PEG/parabènes |
| COSMOS Natural | ≥ 95 % naturel, PAS d'obligation bio |
| Nature et Progrès | Le plus strict : 100 % naturel, 100 % végétaux bio |
| Contraintes bio | TA doux (glucosides), conservateurs limités (Benzoate/Sorbate), pas de silicones |
| Label vs allégation | Logo + certificateur = label. Mention seule = allégation. |
