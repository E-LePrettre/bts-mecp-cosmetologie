# 11 – Objectifs et ressources

Cette séance aborde la **saponification** en tant que réaction chimique conduisant à un produit cosmétique : le **savon**. 
Les étudiants apprennent que le savon est un tensioactif anionique, comprennent ses propriétés et ses limites, et découvrent les alternatives (savon surgras, syndet).

---

## 🎯 Objectifs

### Objectifs scientifiques

- Décrire la **réaction de saponification** (réactifs, produits, conditions)
- Identifier le savon comme **tensioactif anionique** (COO⁻, amphiphile)
- Connaître les **propriétés lavantes** du savon (micelles, CMC)
- Identifier les **limites** (pH alcalin, eau dure, dessèchement)
- Distinguer **savon classique / savon surgras / syndet**

### Objectifs méthodologiques (E2)

- Mobiliser des connaissances de chimie dans un contexte cosmétique
- Analyser une étiquette de savon (INCI)
- Argumenter le choix d'une forme lavante selon le public cible

### Compétences E2 travaillées

| Compétence | Ce qu'on évalue |
|------------|----------------|
| Mobiliser | Connaissances saponification, familles TA |
| Comprendre | Lien réaction chimique → produit cosmétique |
| Analyser | Composition d'un savon, allégations |

## 🔬 "Test rapide" : Saponification et savon

```
1. Quels sont les 2 réactifs de la saponification ?
   → Corps gras (triglycéride) + base forte (NaOH ou KOH)

2. Quels sont les 2 produits ?
   → SAVON (carboxylate) + GLYCÉROL

3. Le savon est un TA de quelle famille ?
   → ANIONIQUE (tête COO⁻)

4. Quel est le pH du savon ? Et celui de la peau ?
   → Savon : 9-10. Peau : 5,5. ÉCART = problème pour peaux sensibles

5. Savon surgras : quelle différence avec le classique ?
   → EXCÈS DE CORPS GRAS non saponifié → effet relipidant
   → MAIS pH reste alcalin

6. Syndet : contient-il du vrai savon ?
   → NON. TA synthétiques doux. pH AJUSTABLE ≈ 5,5
```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Saponification = corps gras + base | → savon + glycérol |
| Savon = TA anionique (COO⁻) | Amphiphile → micelles → lavage |
| pH savon = 9-10 | Alcalin → agression film hydrolipidique |
| Savon surgras = savon + surplus gras | Relipidant mais pH toujours alcalin |
| Syndet ≠ savon | Pas de saponification, pH ajustable, mieux toléré |
| Le choix dépend du public | Peau normale → savon OK. Sensible → syndet ou gel doux |
