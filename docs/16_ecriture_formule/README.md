# 16 – Objectifs et ressources

Cette séance apprend aux étudiants à lire et écrire une formule cosmétique selon les conventions professionnelles : nom INCI, % massique, phases (A/B/C), ordre d'incorporation et qsp. C'est une compétence de communication centrale pour le bloc 2 et l'épreuve E2.

---

## 🎯 Objectifs

### Objectifs scientifiques

- Connaître les **conventions d'écriture** d'une formule cosmétique
- Distinguer les **3 phases** : A (aqueuse), B (huileuse), C (ajouts à froid)
- Comprendre le **% massique** et la contrainte total = 100 %
- Comprendre la notation **qsp 100** (quantité suffisante pour)
- Décrire un **ordre d'incorporation** cohérent
- Savoir **lire** une formule de laboratoire et en extraire les informations

### Objectifs méthodologiques (E2)

- Écrire une formule lisible et complète (tableau professionnel)
- Argumenter les choix de formulation en lien avec l'usage et la cible
- Utiliser la **méthode F.O.R.M.U.L.E.** (FM08)

## 🔬 "Test rapide" : Écriture d'une formule

```
1. Quelles sont les 3 phases d'une formule cosmétique ?
   → A (aqueuse), B (huileuse), C (ajouts à FROID)

2. Que signifie « qsp 100 » ?
   → Quantité Suffisante Pour compléter à 100 % (on ajuste l'eau)

3. Pourquoi le conservateur est-il en phase C ?
   → Parce qu'il est THERMOSENSIBLE (détruit par la chaleur)

4. Dans quel ordre verse-t-on les phases pour une émulsion H/E ?
   → On verse B dans A (huile dans eau) sous agitation vive

5. Un gel aqueux a-t-il une phase B ?
   → NON : pas de corps gras → seulement A + C

6. Le total des % d'une formule doit toujours faire combien ?
   → 100 %
```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Formule = Phase + INCI + Rôle + % | Format standard de laboratoire |
| Total = 100 % toujours | Vérifier systématiquement |
| qsp 100 = on ajuste l'eau | Aqua = 100 − somme des autres % |
| Phase A = aqueuse (70-75 °C) | Eau, glycérine, gélifiants aqueux |
| Phase B = huileuse (70-75 °C) | Huiles, beurres, cires, émulsionnants |
| Phase C = à froid (< 40 °C) | Conservateurs, parfum, actifs fragiles, pH |
| H/E : B dans A | E/H : A dans B |
| Gel : pas de phase B | Solution : pas de phase B non plus |
| FM08 = méthode F.O.R.M.U.L.E. | Fixer/Organiser/Rédiger/Mettre %/Utiliser/Lister/Examiner |
