# 04 – Objectifs et ressources

Cette séance fait le lien entre la **lecture réglementaire** des produits (séances 1-3) et la **pratique de la formulation**. L'objectif est de comprendre que chaque ingrédient d'un produit cosmétique appartient à une **catégorie fonctionnelle** (excipient, actif, additif) et remplit un **rôle précis** dans la formule.
👉 Compétences ciblées : **identifier** les catégories d'ingrédients, **analyser** une composition INCI, **argumenter** la logique d'une formulation (réflexe "épreuve E2").

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Excipients** | Base de la formule (eau, corps gras, émollients, agents de texture) : forme, stabilité, application |
| **Actifs cosmétiques** | Action ciblée : hydratants, anti-âge, kératolytiques, apaisants, dépigmentants, antioxydants |
| **Additifs** | Auxiliaires : conservateurs, parfums, colorants, correcteurs de pH |
| **Formulation raisonnée** | Chaque ingrédient = une fonction ; la formule est un équilibre efficacité/stabilité/sécurité |
| **Double rôle** | Certains ingrédients appartiennent à deux catégories (ex. : Glycerin = excipient + actif) |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Identifier la catégorie et la fonction d'un ingrédient dans une formule |
| **Analyser** | Décoder une liste INCI en reliant chaque ingrédient à son rôle |
| **Argumenter** | Justifier la cohérence d'une formule par rapport à l'objectif du produit |

## 🔬 "Test rapide" : Excipient, actif ou additif ?

```
Pour chaque ingrédient d'une liste INCI, se poser :

1. Est-ce la BASE du produit (eau, corps gras, solvant) ?
   → EXCIPIENT

2. Est-ce l'ingrédient qui fait l'ACTION cosmétique ciblée ?
   (hydrater, lisser, protéger UV, exfolier…)
   → ACTIF

3. Est-ce un ingrédient de SUPPORT ?
   (conservateur, parfum, colorant, correcteur de pH)
   → ADDITIF

⚠️ Certains ingrédients ont un DOUBLE RÔLE :
   - Glycerin = excipient humectant + actif hydratant
   - Tocopherol = actif antioxydant + additif (protège la formule)
```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| **3 catégories** : excipient, actif, additif | Toute analyse de formule commence par ce classement |
| L'**excipient** est aussi important que l'actif | Sans véhicule adapté, l'actif ne pénètre pas et le produit n'est pas stable |
| Un actif appartient à une **famille** | Hydratant, anti-âge, kératolytique, apaisant, dépigmentant, antioxydant |
| La formulation est **raisonnée** | Chaque ingrédient répond à une fonction ; rien n'est ajouté au hasard |

## ⚠️ Lien explicite avec l'épreuve E2

> Objectif : **Analyser une composition cosmétique et identifier le rôle de chaque ingrédient**
> (attendu dans des questions type **E2 2025 – Q9-10, Q13**)

Mini-attendu typique :
- **Je classe** l'ingrédient (excipient / actif / additif),
- **J'identifie** sa fonction dans la formule,
- **Je relie** la composition à l'objectif du produit,
- **Je conclus** sur la cohérence de la formulation.
