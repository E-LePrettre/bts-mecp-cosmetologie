# 18 – Objectifs et ressources

Séance d'étude de cas (EC) sur les contrôles qualité cosmétiques et la vie du produit. Les étudiants apprennent à lire un bulletin de contrôle qualité, identifier les conformités/non-conformités, et argumenter une décision de mise sur le marché. Notion récurrente en E2.

---

## 🎯 Objectifs

### Objectifs scientifiques

- Connaître les **3 stades de vie** du produit (formulation, lot pilote, production)
- Connaître les **4 types de contrôles** (organoleptique, physicochimique, microbiologique, stabilité)
- Comprendre les **méthodes de mesure** (pH-mètre, viscosimètre, conductimètre, challenge test)
- Relier **conductimétrie** → sens de l'émulsion (H/E conduit, E/H ne conduit pas)
- Identifier les **sources de contamination** et les moyens BPF
- Interpréter un **bulletin de contrôle qualité** et argumenter une décision

## 🔬 "Test rapide" : Contrôles qualité

```
1. Citez les 3 stades de vie d'un produit cosmétique.
   → Mise au point (formulation), lot pilote, production industrielle

2. Quel contrôle vérifie l'efficacité du conservateur ?
   → Le CHALLENGE TEST (contamination artificielle)

3. Comment déterminer le sens d'une émulsion par conductimétrie ?
   → H/E conduit (phase continue = eau), E/H ne conduit pas (phase continue = huile)

4. Que signifie PAO ?
   → Période Après Ouverture (obligatoire si durabilité > 30 mois)

5. Que signifie BPF ?
   → Bonnes Pratiques de Fabrication (norme ISO 22716)

6. Citez 4 sources de contamination microbienne en cosmétique.
   → Matières premières, locaux, personnel, conditionnement (+ consommateur)
```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| 3 stades de vie | Formulation → lot pilote → production |
| Challenge test | Contamination volontaire → efficacité conservateur |
| Dénombrement | Comptage germes sur produit fini (< 1 000 UFC/g corps) |
| Conductimétrie | H/E = conduit (eau) ; E/H = ne conduit pas (huile) |
| Stabilité accélérée | 40 °C / 75 % HR → T0, T+1, T+3, T+6 mois |
| BPF | ISO 22716, exigées par CE 1223/2009 |
| PAO | Obligatoire si la durabilité minimale est > 30 mois |
| Conforme / non conforme | Vocabulaire E2 (pas « bon / mauvais ») |
