# S20 – Justification d'un choix galénique 📖 Trace écrite

---

## 1️⃣ Le lien forme ↔ usage ↔ cible ↔ actif ↔ conditionnement

Le choix d'une forme galénique n'est **jamais isolé**. Il se justifie en reliant **5 éléments** :

```
         ┌──────────┐
         │  USAGE   │  (leave-on, rinse-off, jour, nuit, fréquence)
         └────┬─────┘
              │
┌─────────┐   │   ┌─────────┐
│  CIBLE  ├───┼───┤  ACTIFS │  (hydrophile/lipophile, sensible oxydation/lumière)
└─────────┘   │   └─────────┘
 (type peau,  │
  âge, zone)  │
         ┌────┴─────┐
         │  FORME   │  (gel, émulsion H/E, E/H, sérum, baume…)
         │GALÉNIQUE │
         └────┬─────┘
              │
     ┌────────┴────────┐
     │ CONDITIONNEMENT │  (pot, tube, airless, spray…)
     └─────────────────┘
```

---

## 2️⃣ Tableau de synthèse : forme ↔ usage ↔ cible

| Forme galénique | Texture | Usage type | Cible type |
|----------------|---------|-----------|-----------|
| **Gel aqueux** | Légère, fraîche, non grasse | Leave-on jour, compatible maquillage | Peaux mixtes à grasses, jeunes |
| **Émulsion H/E fluide** (lait) | Légère, pénètre vite | Leave-on jour, grandes surfaces | Peaux normales, soin corps, solaire |
| **Émulsion H/E crème** | Onctueuse, nourrissante | Leave-on jour/nuit | Peaux normales à sèches |
| **Émulsion E/H** | Très riche, filmogène | Leave-on nuit, protection | Peaux très sèches, matures, froids |
| **Sérum** | Ultra-fluide, concentré | Leave-on, sous crème | Anti-âge, éclat, traitement ciblé |
| **Baume / stick** | Solide, nourrissant | Leave-on, zones localisées | Lèvres, zones très sèches |
| **Gel lavant / mousse** | Légère, moussante | Rinse-off | Hygiène, nettoyage |

---

## 3️⃣ Les 5 arguments à mobiliser en E2

Pour justifier un choix galénique (type Q14 E2), il faut mobiliser **au moins 4** des 5 arguments :

| Argument | Ce qu'il faut expliquer |
|----------|----------------------|
| **1. Forme → usage** | Pourquoi cette forme est adaptée à l'usage (leave-on/rinse-off, fréquence, durée de contact, zone d'application) |
| **2. Forme → cible** | Pourquoi cette forme convient à ce type de peau / âge / besoin |
| **3. Forme → actifs** | Comment la forme galénique permet de véhiculer les actifs (solubilité : hydrophile dans phase aqueuse, lipophile dans phase grasse) |
| **4. Conditionnement → stabilité** | Comment le conditionnement protège les actifs sensibles (oxydation, lumière, contamination) |
| **5. pH / film hydrolipidique** | Le pH du produit respecte le pH cutané (≈ 5,5) et le film hydrolipidique |

---

## 4️⃣ Modèle de rédaction E2 (structure)

> **Phrase 1** : Nommer la forme galénique choisie.
>
> **Phrases 2-3** : Relier à l'usage et à la cible (pourquoi cette texture pour cette personne et cet usage).
>
> **Phrases 4-5** : Relier aux actifs (comment la forme véhicule les actifs hydrophiles/lipophiles).
>
> **Phrase 6** : Le pH et le film hydrolipidique.
>
> **Phrases 7-8** : Le conditionnement et la stabilité.

**Exemple** : *La forme galénique choisie est un gel aqueux. Cette texture légère et non grasse est adaptée aux peaux mixtes (cible) et à l'usage quotidien matinal (leave-on, compatible maquillage). La phase continue aqueuse solubilise directement les actifs hydrophiles (acide hyaluronique, niacinamide). Le pH est ajusté à 5,5 pour respecter le film hydrolipidique. Le conditionnement en flacon pompe protège le produit et assure un dosage hygiénique.*

---

## 🎓 Message clé

> En E2, la question Q14 vaut souvent **4-6 points**. Le jury attend une argumentation qui **relie** la forme galénique à l'usage, à la cible, aux actifs et au conditionnement. Les meilleurs candidats sont ceux qui expliquent **POURQUOI** (pas ceux qui décrivent QUOI).
