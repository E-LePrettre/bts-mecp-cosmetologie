# 27 – Objectifs et ressources

Séance FE3 + AD (Fiche 3 niveaux + Atelier d'analyse documentaire). Première partie du diptyque parfumerie : voies olfactives, matières premières aromatiques, méthodes d'extraction, IFRA, allergènes, toxicité des HE. Atelier : classement de matières premières à partir de fiches descriptives (sans matériel olfactif).
 
---

## 🎯 Objectifs

- Connaître les **2 voies olfactives** (orthonasale, rétronasale)
- Distinguer matières premières **naturelles** (HE, absolus) et **synthétiques**
- Connaître les **méthodes d'extraction** (distillation, expression, solvant, CO2 supercritique)
- Comprendre le rôle de l'**IFRA** et la déclaration des **26 allergènes** (CE 1223/2009)
- Connaître les **risques** des HE (allergie, phototoxicité, neurotoxicité, irritation)
- Reconnaître les **familles olfactives** et les notes tête/coeur/fond

## 🔬 "Test rapide" : Parfumerie (1/2)

```
1. Quelles sont les 2 voies olfactives ?
   → Orthonasale (par le nez) et rétronasale (par la bouche/pharynx)

2. Quelle méthode pour l'HE de lavande ?
   → Distillation à la vapeur d'eau

3. Quelle méthode pour l'HE de citron ?
   → Expression à froid

4. Qu'est-ce qu'un absolu ?
   → Extrait concentré obtenu par extraction au solvant volatil (via concrète)

5. Combien d'allergènes à déclaration obligatoire (CE 1223/2009) ?
   → 26 allergènes

6. Quel risque spécifique des HE d'agrumes par expression ?
   → Phototoxicité (furocoumarines)
```

## 🔑 Points clés

| Idée clé | À retenir |
|---------|-----------|
| Voies olfactives | Orthonasale / rétronasale |
| MP naturelles | HE (distillation/pression), absolus (solvant), CO₂ supercritique |
| MP synthétiques | Molécules isolées (ex : linalol) pour stabilité/constance/coût |
| Réglementation | IFRA + déclaration des 26 allergènes |
| Risques HE | Allergie/irritation, phototoxicité (agrumes), neurotoxicité possible |
| Familles / notes | Familles olfactives + notes tête/coeur/fond |
