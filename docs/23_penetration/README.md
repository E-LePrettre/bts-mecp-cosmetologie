# 23 – Objectifs et ressources  

Ce chapitre a pour objectif d’amener les étudiants à **expliquer et argumenter la pénétration cutanée d’un actif cosmétique**, en mettant en relation :

- la **barrière cutanée** (couche cornée : modèle « briques et mortier »),
- les **3 voies de pénétration** (intercellulaire, transcellulaire, annexielle),
- les **propriétés physicochimiques** d’un actif (**hydrophilie/lipophilie**, **logP**, **masse molaire**),
- les **facteurs naturels** (zone, hydratation, intégrité cutanée…),
- les **facteurs galéniques** (forme, promoteurs, occlusion, pH, concentration…).

En cosmétologie, “un bon actif” ne suffit pas : **il doit être libéré, pénétrer, diffuser, puis agir**. Cette séance est une **séance charnière** entre physique-chimie (polarité, logP) et cosmétologie (efficacité réelle d’un produit). 

Cette séance constitue une étape importante dans la préparation à **l’épreuve E2 – Expertise scientifique et technologique** (question type **Q11**), où le candidat doit relier **structure → pénétration → efficacité**, et justifier l’influence de la **forme galénique** sur l’efficacité. 
---

## 🎯 Objectifs de la séance

### Objectifs scientifiques et techniques

- Décrire la **barrière cutanée** : couche cornée, modèle **briques et mortier**
- Connaître les **3 voies de pénétration** : intercellulaire, transcellulaire, annexielle
- Comprendre le rôle de la **polarité** et du **logP** dans la pénétration
- Utiliser la règle : **logP optimal 1–3** et **masse < 500 Da**
- Identifier les **facteurs naturels** modulant la pénétration (épaisseur, hydratation, zone, intégrité, température…)
- Identifier les **facteurs galéniques** (forme galénique, concentration, promoteurs, occlusion, pH, vecteurs)
- Argumenter le lien **structure de l’actif → pénétration → efficacité** (niveau E2) 

### Objectifs méthodologiques (E2)

- Mobiliser un vocabulaire précis (ciment lipidique, logP, voie intercellulaire…)
- Exploiter un tableau de données (logP / masse) pour conclure sur la pénétration
- Construire une justification structurée (type Q11 E2) en citant :
  - **propriété(s) de l’actif**,
  - **zone/conditions de peau**,
  - **choix galéniques** (forme, pH, promoteurs, concentration). 

---

## 🧠 Compétences travaillées

- Décrire et expliquer une **barrière biologique** (couche cornée)
- Analyser un **actif** à partir de données physicochimiques (logP, masse)
- Relier la **galénique** à une **efficacité attendue**
- Argumenter comme en situation E2 (réponse structurée, justifiée, professionnelle)

## 🔬 "Test rapide" : Pénétration cutanée

```text
1. Quel est le modèle de la couche cornée ?
   → Briques (cornéocytes) + mortier (ciment lipidique)

2. Quelle est la voie de pénétration principale ?
   → Voie INTERCELLULAIRE (dans le ciment lipidique, majoritaire)

3. Quel est le logP optimal pour pénétrer ?
   → Entre 1 et 3 (modérément lipophile)

4. Pourquoi l’acide hyaluronique (haut PM) ne pénètre-t-il pas ?
   → Masse >> 500 Da : molécule trop grosse, reste en surface

5. Citez 3 facteurs galéniques favorisant la pénétration.
   → Concentration ↑ (Fick), promoteurs, occlusion (ou pH, vecteurs, forme galénique)

6. Pourquoi une molécule neutre pénètre mieux qu’une molécule ionisée ?
   → Les charges traversent mal le ciment lipidique (milieu apolaire)
```



---

## 🔑 Points clés

| Notion               | Ce qu’il faut retenir                                            |
| -------------------- | ---------------------------------------------------------------- |
| Couche cornée        | Barrière principale : **briques + mortier**                      |
| Voie intercellulaire | Voie **majoritaire**, passage dans le ciment lipidique           |
| logP 1–3             | Zone généralement favorable à la pénétration                     |
| Masse < 500 Da       | Condition importante pour traverser la couche cornée             |
| Promoteurs           | Désorganisent/ouvrent le ciment (ex : propylène glycol, éthanol) |
| Occlusion            | Film occlusif → hydratation ↑ → perméabilité ↑                   |
| pH                   | Forme **neutre** pénètre mieux que forme **ionisée**             |
|                      |                                                                  |

---

> **Remarque pédagogique – Épreuve E2 (Q11)**
>
> En E2, on attend une réponse qui relie explicitement :
> **(1) structure de l’actif (logP, masse, ionisation)** → **(2) voie/limites de pénétration** → **(3) choix galéniques qui compensent** (forme, promoteur, pH, occlusion, concentration).
>
> Retenir : la **voie intercellulaire** est la voie principale et la pénétration est souvent optimale pour **logP 1–3** et **M < 500 Da**.
