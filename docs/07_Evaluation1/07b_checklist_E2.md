# ✅ MOBILISER (4 points)

> *Utiliser les connaissances cosmétologiques et réglementaires*

## Connaissances à mobiliser (S01-S06)

### S01 – Définition du produit cosmétique

| ✓ | Je sais... |
|---|------------|
| ☐ | Donner la **définition** d'un produit cosmétique (3 critères : nature, zones, finalités) |
| ☐ | Distinguer un cosmétique d'un **médicament** (pas de revendication thérapeutique) |
| ☐ | Distinguer un cosmétique d'un **biocide** (pas d'action désinfectante revendiquée) |
| ☐ | Vérifier si un produit **est un cosmétique** en appliquant les 3 critères |

### S02 – Réglementation

| ✓ | Je sais... |
|---|------------|
| ☐ | Citer le **règlement CE 1223/2009** |
| ☐ | Expliquer l'exigence de **sécurité** (article 3) |
| ☐ | Définir la **personne responsable** et son rôle (article 4) |
| ☐ | Citer le **DIP** et son contenu (5 éléments) |

### S03 – Étiquetage et INCI

| ✓ | Je sais... |
|---|------------|
| ☐ | Expliquer les **règles de la nomenclature INCI** |
| ☐ | Interpréter l'**ordre décroissant** des ingrédients |
| ☐ | Identifier les **allergènes** à déclaration obligatoire |
| ☐ | Expliquer le seuil de **1 %** et la liberté d'ordre en dessous |
| ☐ | Identifier les mentions obligatoires de l'étiquetage (PAO, lot, personne responsable) |

### S04 – Composition

| ✓ | Je sais... |
|---|------------|
| ☐ | Distinguer les **3 catégories** : excipients, actifs, additifs |
| ☐ | Donner des ordres de grandeur : excipient = support (souvent majoritaire) ; actif = action ciblée (dosage variable, souvent 0,1–10 %) ; additif = faible dose (souvent < 5 %) |
| ☐ | Classer des ingrédients INCI dans leur catégorie |
| ☐ | Expliquer le **double rôle** de certains ingrédients (ex : Glycerin, Tocopherol) |
| ☐ | Citer des **familles d'actifs** cosmétiques (hydratants, apaisants, antioxydants…) |

### S05 – Sécurité

| ✓ | Je sais... |
|---|------------|
| ☐ | Définir la **sécurité** d'un produit cosmétique |
| ☐ | Définir la **cosmétovigilance** |
| ☐ | Distinguer **effet indésirable** et **effet indésirable grave** |
| ☐ | Citer les acteurs du contrôle : **ANSM**, **DGCCRF** |
| ☐ | Expliquer l'**obligation de déclaration** |

### S06 – Tensioactifs

| ✓ | Je sais... |
|---|------------|
| ☐ | Définir un **tensioactif** |
| ☐ | Expliquer « molécule **amphiphile** » (hydrophile + hydrophobe) |
| ☐ | Décrire le **mécanisme de nettoyage** (micelles) |
| ☐ | Citer les **4 familles** de tensioactifs |
| ☐ | Associer chaque famille à un **pouvoir lavant** et un **niveau de douceur** |
| ☐ | Expliquer pourquoi on **associe** plusieurs tensioactifs |
| ☐ | Relier le **choix** des TA à l'**usage** et à la **tolérance cutanée** |

# 🔴 ERREURS FRÉQUENTES À ÉVITER

## Erreurs de contenu

| ❌ Erreur | ✅ Correction |
|----------|--------------|
| Oublier un critère de la définition du cosmétique | Toujours vérifier : nature + zones + finalités |
| Confondre cosmétique et médicament | Le cosmétique ne revendique PAS d'effet thérapeutique |
| Dire que le SLS est « dangereux » | Il est « plus détergent » ou « moins bien toléré » |
| Croire que mousse = efficacité | La mousse est un critère sensoriel, pas d'efficacité |
| Confondre excipient et actif | Excipient = support (souvent majoritaire), actif = action ciblée (dosage variable) |
| Oublier le double rôle du Glycerin | Humectant (excipient) ET hydratant (actif) |

## Erreurs sur la sécurité

| ❌ Erreur | ✅ Correction |
|----------|--------------|
| « Le produit est dangereux » | Nuancer : le produit est conforme MAIS un EI est survenu |
| « Le labo est en faute » | Vérifier : l'allergène est-il déclaré dans la liste INCI ? |
| « Effet indésirable = grave » | Grave = hospitalisation, incapacité, pronostic vital |
| Pas de mention du DIP | Le DIP doit être mis à jour après tout signalement |

## Erreurs de rédaction

| ❌ Erreur | ✅ Correction |
|----------|--------------|
| Réponse sans justification | Ajouter « car... » ou « en effet... » |
| « C'est un cosmétique parce que c'est un gel douche » | Justifier avec les 3 critères du règlement |
| « Les tensioactifs lavent » | Préciser : « Les TA sont des molécules amphiphiles qui... » |
| Synthèse trop courte | Vérifier les 5 éléments attendus |

## 📌 Repères essentiels à connaître

| Notion | Repère |
|--------|--------|
| Définition cosmétique | 3 critères : nature, zones superficielles, finalités |
| Règlement | CE 1223/2009 |
| Excipient | Support de la formule, souvent majoritaire |
| Actif | 0,1 à 10 %, action ciblée |
| Additif | < 5 %, conservation/texture/couleur/parfum |
| TA anioniques classiques | Lavant fort, douceur faible (SLS, SLES) |
| TA anioniques doux | Lavant modéré, bonne douceur (Cocoyl Glutamate) |
| TA amphotères | Lavant modéré, bonne douceur (Betaine) |
| TA non ioniques | Lavant doux, très bonne douceur (Glucoside) |
| Allergènes INCI | 26 substances, déclaration obligatoire > 0,01 % (rincé) ; > 0,001 % (non rincé) |
| EI grave | Hospitalisation, incapacité, pronostic vital |
