## 🔬 "Test rapide" : Ai-je bien révisé ?

```
1. Je peux citer les 3 CRITÈRES de la définition du cosmétique ?
   → nature, zones superficielles, finalités

2. Je connais les 4 FAMILLES de tensioactifs et leur douceur ?
   → anioniques (fort), amphotères (moyen), non ioniques (doux), cationiques (conditionnement)

3. Je sais distinguer EXCIPIENT / ACTIF / ADDITIF ?
   → excipient = support (souvent majoritaire), actif = action ciblée (dosage variable), additif = conservation/texture

4. Je sais analyser un SIGNALEMENT (EI, gravité, cause) ?
   → lien temporel, réversibilité, grave = hospitalisation

5. Je peux citer 5 éléments du DIP ?
   → description, sécurité, BPF, preuves, données relatives à l’expérimentation animale (le cas échéant)
```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Un cosmétique = **3 critères** | Substance/mélange + parties superficielles + finalités |
| La sécurité est une **obligation** | Règlement CE 1223/2009, article 3 |
| INCI = ordre **décroissant** | 1er = solvant, derniers = allergènes ou < 1 % |
| 3 catégories de composition | Excipients (support), actifs (action), additifs (conservation/texture) |
| Le choix des TA dépend de l'**usage** | Zone, public, fréquence → famille adaptée |
| Cosmétovigilance ≠ « c'est dangereux » | Analyse professionnelle : EI, gravité, cause, actions |

## 💡 Conseils de révision

### La veille

1. Relire les **traces écrites** S01 à S06
2. Réviser les **3 critères** de la définition du cosmétique
3. Revoir les **familles de TA** et leur niveau de douceur
4. Revoir le **contenu du DIP** (5 éléments)
5. Parcourir la **checklist E2**

### Le jour J

1. Lire **tout le dossier** avant de commencer
2. **Surligner** les infos clés dans chaque document
3. **Justifier** chaque réponse avec les documents
4. Soigner le **vocabulaire cosmétologique**
5. **Vérifier** avec la checklist avant de rendre
